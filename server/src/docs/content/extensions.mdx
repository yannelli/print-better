Extensions are optional features that ship with Print Better. Each one stays off until you turn it on, so a server that doesn't need it works exactly as before.

## Available extensions

| Extension | What it does |
| --- | --- |
| [Printer access](/docs/extensions/printer-access) | Choose who can see, print to, and manage each printer, with groups, device rules, and custom roles. |

## Turn on an extension

An extension needs two switches. A server admin makes it available on the server. Then a workspace owner turns it on for their workspace. It works only where both are on.

<Steps>

### Make it available on the server

A server admin opens [**Server admin**](/admin/extensions) and selects the **Extensions** tab. Turn on **Available to workspaces** next to the extension.

### Turn it on for the workspace

A workspace owner opens [**Settings**](/settings) and finds the **Extensions** section. Turn on the extension's switch, read what changes, and select **Turn on**.

</Steps>

Pages that are already open update without a reload. Devices update their print windows too.

In **Workspace settings**, each extension shows where it stands:

| Status | What it means |
| --- | --- |
| **Not available on this server. Ask a server admin to make it available.** | The server admin switch is off. |
| **Off** | Available, but this workspace hasn't turned it on. Admins and members see **Off. Only owners can turn it on.** |
| **On for this workspace** | Both switches are on. Admins and members see **On. Only owners can turn it off.** |
| **Paused because a server admin made it unavailable. Your setup is kept.** | The workspace turned it on, but a server admin turned it off for the server. |

On the server admin's **Extensions** tab, each extension shows how many workspaces turned it on.

## Turn off an extension

Either switch turns an extension off.

- A workspace owner turns off the extension's switch in **Settings**, then selects **Turn off**. This affects only that workspace.
- A server admin turns off **Available to workspaces**. This stops the extension in every workspace at once.

The usual rules come back right away. Print Better keeps the extension's data, such as groups and roles. Turn the extension back on and everything is as you left it. The data is deleted only with the workspace or printer it belongs to.

## How extensions behave

- **Off means unchanged.** While an extension is off, Print Better behaves exactly as if it didn't exist.
- **The same rules everywhere.** An extension's rules apply in the web app, the API, AI assistants, email to print, and on devices.
- **Every change is recorded.** Turning an extension on or off, and every change it makes, appears in [Activity](/docs/workspaces/activity).
- **No update needed.** Extensions ship with the server, so turning one on never needs a new deploy.

AI assistants see an extension's tools once a server admin makes it available. While it is off in a workspace, those tools explain how to turn it on. See [MCP tools](/docs/reference/mcp).
