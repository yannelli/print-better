The service starts by itself, finds nearby printers, and prints the jobs sent to them.

## Requirements

- A 64-bit Intel or AMD computer, or an ARM computer. Builds exist for `x86_64`, 64-bit ARM, ARMv7, and ARMv6.
- systemd, `curl`, and `tar`.
- `sudo`, or a root shell, for a machine-wide install.
- An owner or admin role in the workspace, to add a device.

## Install

<Steps>

### Copy the Install Command

Open [Add a device](/devices/add) in the web app. Choose **Linux computer** and select **Continue**. Copy the command under **Install command**.

### Run It on the Computer

Open a terminal on the Linux computer. Paste the command and press Enter. It looks like this:

```sh
curl -fsSL https://your-print-better.example/install.sh | sh -s -- --token pbe_...
```

### Wait for It to Connect

The script downloads the build for your CPU, checks its SHA-256 checksum, installs it, connects it to the workspace, and starts the service. The web page moves on by itself when the device connects.

</Steps>

The setup code in the command works once.

To update Print Better later, run the same command again. It keeps the connection.

## User Service or System Service

| | User service | System service |
| --- | --- | --- |
| Chosen when | You run it as a normal user in a desktop session | You run it as root, or there is no desktop session |
| Program | `~/.local/bin/printbetter` | `/usr/local/bin/printbetter` |
| systemd unit | `~/.config/systemd/user/printbetter.service` | `/etc/systemd/system/printbetter.service` |
| Runs as | You | The system user `printbetter`, in the `lp` and `lpadmin` groups (`lpadmin` where the system has it) |
| Starts | When you log in | When the computer starts |
| Settings and pairing | `~/.config/printbetter/` | `/etc/printbetter/` |
| State and log | `~/.local/state/printbetter/` | `/var/lib/printbetter/` |

A user service stops when you log out. To keep it running while nobody is logged in, run:

```sh
loginctl enable-linger "$USER"
```

The system service also installs:

- A udev rule, `/etc/udev/rules.d/60-printbetter.rules`, so the service can open USB printers.
- A small updater that runs as root, `printbetter-update.path` and `printbetter-update.service`. It lets the service install updates. See [Automatic Updates](/docs/devices/updates#linux-system-service).

If a user service exists when you install the system service, the system service removes it and keeps its connection.

## Install Script Options

Add options after `sh -s --`:

| Option | What it does |
| --- | --- |
| `--token TOKEN` | Connects to the workspace with a `pbe_` setup code. |
| `--name NAME` | The device name shown in Print Better. |
| `--system` | Installs the system service. Implies `--no-tray`. |
| `--no-tray` | Runs without a tray icon. |
| `--version V` | Installs a specific version instead of the newest one. |

## Control the Service

```sh
printbetter service status
printbetter service restart
printbetter service stop
printbetter service start
```

Use `sudo` to start, stop, or restart the system service. Commands such as `printbetter status` and `printbetter doctor` work as any user. See [Command Line](/docs/reference/cli).

## Logs

| Install | Read the log |
| --- | --- |
| User service | `journalctl --user -u printbetter` or `~/.local/state/printbetter/logs/printbetter.log` |
| System service | `journalctl -u printbetter` or `/var/lib/printbetter/logs/printbetter.log` |

`printbetter logs --follow` shows the same log for either kind.

## Printers in the Print Window

On a Linux desktop with CUPS, Print Better adds every added printer on your other devices to the computer's printers. Apps show them in their print window. This is on by default. See [From Your Computer's Print Window](/docs/printing/print-window).

Adding these printers needs CUPS admin rights. CUPS gives them to root and to members of its admin group, which is often `lpadmin`. Computers without CUPS skip this feature.

## Remove Print Better

<Steps>

### Remove the Device

While the computer is online, remove it on its page in the web app. See [Manage Devices](/docs/devices/manage#remove-a-device). You can also run `printbetter unpair`.

### Remove the Service

For a user service, run `printbetter service uninstall`. For the system service, run:

```sh
sudo printbetter service uninstall --system
```

Settings stay in `/etc/printbetter` and `/var/lib/printbetter`. Delete the program file and those folders if you don't need them.

</Steps>
