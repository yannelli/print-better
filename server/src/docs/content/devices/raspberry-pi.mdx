The Pi sits next to your printers, connects them to Print Better, and prints the jobs sent to them.

## What You Need

- A Raspberry Pi and a memory card.
- Another computer with a card reader and Raspberry Pi Imager.
- A Wi-Fi network or a network cable.
- An owner or admin role in the workspace.

Use the operating system that matches your Pi:

- Pi 3, 4, 5, or Zero 2 W: Raspberry Pi OS (64-bit)
- Pi Zero, Zero W, Pi 1, or Pi 2: Raspberry Pi OS (32-bit)

The ARMv6 build for the Pi Zero, Zero W, and Pi 1 is best effort.

## Set Up a New Pi

The web app writes 3 setup files for the memory card. It makes them in your browser, so your Wi-Fi and Pi passwords never reach the server.

<Steps>

### Fill In the Form

Open [Add a device](/devices/add). Choose **Raspberry Pi** and select **Continue**. Fill in **Set up your Raspberry Pi**:

| Field | What to enter |
| --- | --- |
| **Name for the Pi** | Its name on your network and in Print Better, such as `kitchen-pi`. Lowercase letters, numbers, and dashes. |
| **How will it connect to the internet?** | **Wi-Fi** or **Network cable**. |
| **Wi-Fi network name**, **Wi-Fi password**, **Country** | Your Wi-Fi details. Check **This network is hidden** for a hidden network. |
| **Username** and **Password** | An account for signing in to the Pi later. |
| **SSH public key (optional)** | Your public key, if you sign in with SSH keys. |
| **Time zone** | The Pi's time zone. |

Select **Create setup files**.

### Download the Files

Under **Prepare the memory card**, select **Download all three files**. You get `user-data`, `network-config`, and `meta-data`.

### Write the Memory Card

Open Raspberry Pi Imager on your computer. Choose your Pi model and the operating system above, then your memory card.

When Imager asks about settings, select **Edit settings** and turn on at least 1, such as the hostname. The Pi reads the setup files only when a setting is on. Write the card.

### Copy the Files

Take the card out and put it back in. Open the drive called `bootfs`. Copy the 3 files onto it and replace the files already there.

Keep the names exactly `user-data`, `network-config`, and `meta-data`, with nothing added to the end.

### Start the Pi

Put the card in the Pi and plug in the power. Select **I’ve started the Pi** on the web page.

</Steps>

The first start takes about 5 to 10 minutes. The Pi joins your network, installs Print Better, and connects to your workspace. The web page notices by itself and moves on to choosing printers.

The setup code in the files works once, for 7 days. If the Pi doesn't connect, see [A Device Shows Offline](/docs/reference/troubleshooting#a-device-shows-offline).

## What the Setup Files Do

On its first start, the Pi:

- Sets its name, time zone, and network from your answers.
- Creates your user with `sudo` rights that don't ask for a password, and turns on SSH.
- Runs the Linux install command with `--system --no-tray` and the Pi's name. It retries for about 10 minutes while the network comes up.

To review the files before you copy them, open **See what’s inside the files**.

## Install on a Pi That Already Runs

Use the Linux steps on a Pi that runs Raspberry Pi OS or another Linux. Choose **Linux computer** in **Add a device** and run the command on the Pi. Without a desktop session, it installs the system service. See [Install on Linux](/docs/devices/linux).

## How the Pi Runs

The Pi runs Print Better as a system service under the `printbetter` user, from startup. It can print to:

- Network printers that announce themselves with Bonjour.
- Older network printers it finds with SNMP.
- USB printers plugged into the Pi. A udev rule lets the service open them.

The web app lists the Pi as **Raspberry Pi or Linux**.

Settings and pairing are in `/etc/printbetter/`. The log is in `/var/lib/printbetter/logs/printbetter.log`, and `journalctl -u printbetter` shows it too.
