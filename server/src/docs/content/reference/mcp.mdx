## The Server Address

```text
https://your-print-better.example/mcp
```

The **Connect AI** page in the web app shows the same address and the steps for each assistant.

Tools call the same code as the web app and the REST API, so the same roles and permissions apply.

## Signing In

Assistants sign in with OAuth. When one connects, Print Better opens a page that asks whether to let the app use Print Better, and lists what the app will be able to do.

1. Under **Which workspace can it use?**, choose 1 workspace or **All my workspaces**.
2. Choose **Allow** or **Don't allow**.

- The access token lasts 1 hour. The refresh token lasts 30 days and changes on every use.
- Reusing an old refresh token disconnects the app, in case someone copied it.
- A connection request expires after 10 minutes.

To disconnect an app, open **Your account**, then **Apps and tokens**. Under **Connected apps**, select **Disconnect**.

The MCP server accepts only bearer tokens, never the browser cookie. It takes personal API tokens (`pbt_`) and OAuth tokens issued for this address (`pbo_`).

## Scopes

| Scope | Shown on the consent page as | Tools |
| --- | --- | --- |
| `read` | See your printers, devices and print jobs | Tools that list and get. |
| `print` | Print documents on your printers | `print`, `print_test_page`, `cancel_job`, `retry_job`. |
| `write` | Change settings, devices and people | Every other tool that changes something. |

Personal API tokens hold all 3. When an assistant asks for none of them, it gets all 3. A missing scope returns `403` with `insufficient_scope`, so the assistant can ask for more.

## Which Workspace a Tool Uses

A tool picks its workspace in this order:

1. The workspace the connection is limited to, if any.
2. Otherwise the `workspaceId` argument.
3. Otherwise your only workspace. With several, the tool asks for a `workspaceId` and lists your choices.

## Tools

Start with `get_setup_status`. It returns a checklist for the workspace and the next tool to call.

| Tool | Scope | What it does |
| --- | --- | --- |
| `get_setup_status` | `read` | Checklist: devices paired and online, printers added, first print, members. Suggests the next tool. |
| `whoami` | `read` | You, your workspaces and roles, whether you are a server admin, and any workspace limit. |
| `list_workspaces` | `read` | Your workspaces and your role in each. |
| `create_workspace` | `write` | Creates a workspace with you as its owner. |
| `update_workspace` | `write` | Renames a workspace or changes its settings: auto-add, retention, retry time, upload limit, network sharing, email to print, default printer. |
| `list_members` | `read` | Members and their roles. |
| `invite_member` | `write` | Creates an invite link that works for 7 days. Emails it when you give an address and email is set up. |
| `update_member_role` | `write` | Changes a member's role. Owner rules apply. |
| `remove_member` | `write` | Removes a member, or leaves the workspace. |

| --- | --- | --- |

| `delete_group` | `write` | Admins: deletes a group and its grants. |

| `list_printer_roles` | `read` | Built-in and custom roles with their permissions. |
| `create_printer_role` | `write` | Admins: creates a custom role. |
| `update_printer_role` | `write` | Admins: edits a custom role. |
| `delete_printer_role` | `write` | Admins: deletes a custom role that nothing uses. |

| `set_printer_everyone_role` | `write` | Sets a printer's Everyone role, or the workspace default without `printerId`. |
| `grant_printer_access` | `write` | Gives a member, group, or device a role on one printer, or on every printer without `printerId`. |
| `revoke_printer_access` | `write` | Removes a grant. |
| `explain_printer_access` | `read` | Explains why someone has their permissions on a printer. |

These tools need the [Enterprise Controls](/docs/extensions/enterprise) extension, and most need their part turned on too. They are listed once a server admin makes it available.

| Tool | Scope | What it does |
| --- | --- | --- |
| `get_enterprise_settings` | `read` | Each part's settings, and printers with approval or release on. |
| `update_enterprise_settings` | `write` | Admins: turns parts on or off and changes their settings. Owners for retention and privacy. |
| `set_printer_controls` | `write` | Turns **Every job needs approval** or **Hold jobs until released** on or off for a printer. |
| `list_approvals` | `read` | Jobs waiting for your approval, oldest first. |
| `approve_job` | `print` | Approves a job, with an optional note. |
| `deny_job` | `print` | Cancels a job waiting for approval, with a reason the sender sees. |
| `list_ready_to_release` | `read` | Your jobs waiting to be released. Admins can ask for everyone's. |
| `release_job` | `print` | Releases a held job so it prints. Without `jobId`, releases all of yours. |
| `list_cost_centers` | `read` | Cost centers, and your default. |
| `create_cost_center` | `write` | Admins: adds a cost center. |
| `update_cost_center` | `write` | Admins: renames, recodes, or deactivates one. |
| `delete_cost_center` | `write` | Admins: deletes one no job was charged to. |
| `set_cost_center_defaults` | `write` | Admins: sets or removes the default for members, groups, and devices. |

## Results and Errors

Each result has structured content and 2 text blocks: a short summary, then the same data as JSON.

When a tool can't do what you asked, the result is marked as an error with a plain message, such as "Choose a printer". The assistant can read it and try again.

Every change a tool makes appears in the workspace's activity log.

## Protocol Details

- Transport: streamable HTTP at `POST /mcp`, stateless, with JSON responses.
- Protocol versions: `2026-07-28`, plus `2025-11-25`, `2025-06-18`, and `2025-03-26` through `initialize`.
- Requests can be up to 16 MB. A `base64` document can be about 12 MB.
- OAuth discovery: `/.well-known/oauth-protected-resource/mcp` and `/.well-known/oauth-authorization-server`.
- The server offers tools only. It has no resources or prompts.
