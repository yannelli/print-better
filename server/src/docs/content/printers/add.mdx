Your devices find printers on their own. This page shows you how to choose which of those printers people in your workspace can print to.

## Found and added printers

Each device looks for printers on its network, over USB, and in its computer's own printer list. See [Printer discovery](/docs/devices/discovery) for how it searches. Every printer a device finds appears on the **Printers** page, in one of two states:

- **Added**: people can print to it from the web app, the API, AI assistants, email, and the print window on their other computers.
- **Found but not added**: Print Better knows about it, but nobody can print to it yet.

Owners and admins can add printers. With [Printer access](/docs/extensions/printer-access) turned on, anyone with the **Change settings** permission on a printer can add it too. Members see **Ask an admin to add one.**

## Add a printer

<Steps>

### Open the Printers page

Open [**Printers**](/printers) from the sidebar.

### Find the printer

Scroll to **Found but not added**. Each row shows the printer's model and the device that found it.

### Add it

Select **Add** next to the printer. A message says the printer is ready to use, and it moves to the top of the page.

</Steps>

You can also open a found printer and select **Use this printer** under **Tools**.

When you add a new device, its **Choose the printers to use** step does the same job. Select the printers you want, then select the add button, for example **Add 2 printers**.

## Add printers automatically

Print Better can add a printer as soon as a device finds it for the first time. Choose how in [**Settings**](/settings), under **New devices and printers** > **Add printers automatically**.

| Choice | What happens |
| --- | --- |
| **Recommended** | Adds printers connected by USB. Adds network printers only when the device finds 3 or fewer of them. This is the default. |
| **All of them** | Adds every printer a device finds. |
| **Ask me first** | Adds nothing. New printers wait under **Found but not added**. |

Select **Save changes** to apply your choice.

Each device can also follow its own rule. Open the device from [**Devices**](/devices), then choose under **New printers**:

| Choice | What happens |
| --- | --- |
| **Use the workspace setting** | Follows the choice in workspace settings. This is the default. |
| **Add the likely ones** | Same as **Recommended**. |
| **Add every printer found** | Same as **All of them**. |
| **Ask me first** | New printers from this device wait until you add them. |

Automatic adding applies only to printers a device sees for the first time. A printer that another device already added is the same printer. It isn't added twice, and it doesn't appear under **Found but not added**.

## Stop using a printer

Open the printer. Under **Tools**, select **Stop using**.

The printer leaves the print menu and goes back to **Found but not added**. Its settings stay, so you can add it again later. If it was the workspace's default printer, the workspace no longer has one.

## Forget a printer

Open the printer. Under **Tools**, select **Forget printer**, then confirm with **Forget printer**.

Print Better removes the printer, its default settings, and its sharing options. Jobs still waiting for it are canceled with the message **Printer removed**. Past jobs stay in **Print jobs**. If a device finds the printer again, it comes back as a new printer.
