Give a printer its own email address. Anyone you allow can then print by sending a document to it from any phone or computer.

Email to print is off by default. Three things must be on, in this order:

1. The server receives email. A server admin sets this up once. See [Email](/docs/self-hosting/email).
2. The workspace allows printing by email.
3. The printer has an email address.

## Allow printing by email in a workspace

Owners and admins can change these settings.

<Steps>

### Open Email to print

Open [**Settings**](/settings) and find **Email to print**.

### Turn it on

Turn on **Allow printing by email**.

### Choose who can send

**Accept email from members** lets anyone in the workspace print from the email address on their account. It is on by default.

To accept other senders, list them under **Also accept email from**. Write one address per line, such as `alex@example.com`. Start a line with `@` to allow a whole domain, such as `@example.com`.

### Save

Select **Save changes**.

</Steps>

If the server doesn't receive email yet, the section says **Incoming email isn’t set up on this server yet.**

## Give a printer an email address

<Steps>

### Open the printer

Open [**Printers**](/printers) and select the printer.

### Turn on Print by email

Under **Sharing**, turn on **Print by email**.

### Choose its email name

Type a name under **Email name for this printer**, such as `kitchen`. Then select **Save name**.

</Steps>

The printer's address is that name, then `@`, then the email domain your server admin set up. For example, `kitchen@print.example.com`.

Names use lowercase letters, numbers, dots, dashes, and underscores. They start and end with a letter or a number. Each name belongs to one printer on the whole server. If another printer uses it, saving fails with **That email alias is already used by another printer**.

## Send a document

Send an email to the printer's address, with the documents attached.

- Each attachment prints as its own job. Print Better prints up to 10 attachments from one message.
- Attachments can be PDF, JPG, PNG, or plain text files. Other files are skipped.
- Each attachment must fit the workspace's upload limit, 50 MB unless an admin changed it.
- Pictures inside the message, such as logos and signatures, never print.
- With no printable attachment, the text of the message prints instead.

Jobs use the printer's [default settings](/docs/printers/settings#default-settings). They appear in [**Print jobs**](/jobs) as **From email**, titled with the file name or the subject.

## Who can print by email

A message prints only when the sender is allowed:

- **Members** must send from the email address on their Print Better account, and that address must be verified. To check, open [**Your account**](/account). A verified address shows **Verified**. Otherwise, select **Send verification email**.
- **Other senders** must match an entry in **Also accept email from**.

Mail that fails the sender's DMARC check never prints. This stops people from faking an allowed address.

With [Printer access](/docs/extensions/printer-access) turned on, a member also needs the **Print** permission on the printer. Other senders can print only to printers where **Everyone** has the **Print** permission.

## When a message doesn't print

The server refuses the message when:

- no printer has email turned on at that address;
- the sender isn't allowed to print there;
- the message has nothing printable.

With Cloudflare Email Routing, the sender gets a bounce that gives the reason. With Resend inbound, the message is dropped without a reply.
