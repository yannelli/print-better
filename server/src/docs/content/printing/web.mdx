Print a file or some text from any browser. The web app works the same on a computer, a tablet, or a phone.

## Before you start

You need a Print Better account in a workspace with at least one added printer. If the print dialog says **No printers yet**, an owner or admin needs to [add a device](/docs/quickstart) and [add a printer](/docs/printers/add).

## Print a file

<Steps>

### Open the print dialog

Select **Print something** on the **Printers** or **Print jobs** page. On **Home**, select the sheet of paper, or drop a file onto it.

To start with a printer already chosen, select **Print** on that printer's card.

### Choose the file

On the **A file** tab, select **Drop a file here, or choose one**. Pick a PDF, a JPG or PNG photo, or a plain text file.

### Choose a printer

Pick one under **Printer**. The dialog starts with the workspace's default printer when there is one.

### Check the settings

The dialog starts with the printer's [default settings](/docs/printers/settings#default-settings). Change any of them for this print.

### Print

Select **Print**. A progress bar shows the upload.

</Steps>

When the job reaches the server, the dialog shows **Sent to** and the printer's name. The status updates live until the page prints. Select **Print another** to send more, or **Done** to close.

## Print some text

Select **Print something**, then open the **Some text** tab. Type or paste the text and select **Print**.

The first line of the text becomes the job's title in [**Print jobs**](/jobs).

## Settings in the dialog

The dialog shows only the settings the printer supports.

| Setting | What it does |
| --- | --- |
| **Copies** | How many copies to print. |
| **Color** | **Color** or **Black and white**. Color printers only. |
| **Sides** | **One side**, **Both sides, like a book**, or **Both sides, flip up**. Printers that print on both sides only. |
| **Paper** | The paper size. |
| **Pages** | Which pages to print, such as `1-3, 5`. Leave it empty to print everything. |

Select **More options** for three more:

| Setting | What it does |
| --- | --- |
| **Page direction** | **Automatic**, **Portrait (tall)**, or **Landscape (wide)**. |
| **Size on the page** | **Shrink to fit the page**, **Fill the whole page**, or **Actual size**. |
| **Quality** | **Draft (faster, uses less ink)**, **Normal**, or **Best**. |

The dialog sends only the settings you change. Everything else follows the printer's defaults. See [Job options](/docs/reference/job-options) for details.

## File types and size

You can print PDF, JPG, PNG, and plain text files. Other files show **This kind of file can’t be printed yet.**

Files can be up to 50 MB unless an admin changed the limit. A larger file shows its size and the limit.

Admins change the limit in **Settings** > [**Printing**](/settings/printing). See [Workspace settings](/docs/workspaces/settings#print-jobs).

## When the printer isn't ready

You can still print. Under **Printer**, the dialog says what is wrong and that the job prints as soon as the printer is ready. An offline printer is marked **(offline)** in the list.

The job waits on the server and prints when the printer and its device are back. If it makes no progress for 24 hours, it stops with **Didn't print**.

Admins can change that time in **Settings** > [**Printing**](/settings/printing). See [Workspace settings](/docs/workspaces/settings#print-jobs).

## Stop an upload

While a file uploads, select **Stop upload**. Print Better cancels the job. The dialog stays open until the upload ends or stops.

## Print from your phone

Open your Print Better address in your phone's browser and sign in. Everything on this page works the same way. **Drop a file here, or choose one** opens your photos and files.
